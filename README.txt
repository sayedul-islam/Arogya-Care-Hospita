Arogya Care Hospital — Advanced Practice Website
====================================================
Files:
- index.html
- about.html
- departments.html
- doctors.html
- appointment.html
- contact.html
- css/style.css
- js/script.js
- images/hero.png

Run:
1. Open the project folder in VS Code.
2. Use Live Server on index.html.
3. Replace images/about.png and any future doctor images with your own Canva assets if desired.

What was improved:
- Hero redesigned around the supplied/generated 1920×800 visual direction.
- Responsive navigation with mobile menu.
- Strong typography, spacing, hierarchy and accessible focus states.
- Hover/motion effects with reduced-motion support.
- Department cards and doctor filters driven by JavaScript.
- Appointment form with department/doctor dependency, date minimum and localStorage.
- Contact form validation.
- Shared navigation/footer injected consistently so pages stay linked.
- All major CTA links point to existing pages.
